# 형제의 대장간 V0.2.5b

V0.2.5a의 1층 동선·작업 안내·2층 생활공간 리디자인을 유지하면서, 남아 있던 **2층 충돌/동선 안정성**과 **좁은 화면 작업 안내**를 보강한 안정화판입니다.

## 실행

### Windows
압축을 완전히 푼 뒤 `RUN_GAME.bat`을 더블클릭합니다. Node.js가 설치되어 있어야 합니다.

### 개발 서버
```bash
npm run dev
```
브라우저에서 `http://localhost:5173` 접속.

### 테스트 / 빌드
```bash
npm test
npm run build
```
`dist/`는 Render Static Site 같은 정적 웹호스팅에 바로 배포할 수 있습니다.

Render 기준:
- Build Command: `npm run build`
- Publish Directory: `dist`

## V0.2.5b 추가 안정화

### 2층도 실제 공간으로 처리
V0.2.5a에서 2층은 생활감 중심으로 재배치했지만 가구 충돌은 1층보다 단순했습니다. V0.2.5b에서는 별도의 `loftWorld`를 추가했습니다.

충돌 적용:
- 형 침대
- 동생 침대
- 공용 테이블
- 형의 큰 궤짝
- 동생의 개인 상자
- 2층 계단 랜딩
- 방 외곽 경계

따라서 침대나 궤짝을 그대로 관통하거나 2층 벽 위로 올라가는 움직임을 막습니다.

### 2층 상호작용 포인트 분리
가구의 중앙이 아니라 실제로 사람이 설 수 있는 위치를 `LOFT_INTERACTION_POINTS`로 분리했습니다.
침대, 공용 테이블, 수납장, 창문, 등불, 계단을 가구 안으로 들어가지 않고 사용할 수 있습니다.

### 계단 랜딩 추가 안정화
1층→2층 이동 시 오른쪽 계단 구조와 겹치지 않는 walkable 안전 지점으로 이동합니다. 2층→1층 역시 기존 안전 스폰과 0.35초 재진입 쿨다운을 유지합니다.

### 좁은 화면 작업 안내 보완
1490px 미만에서는 2x 정수 픽셀 스케일을 지키기 위해 외부 사이드 작업 패널을 숨깁니다. 대신 게임 캔버스 안에 작은 **현재 작업 / 현재 단계 / 다음 단계** 요약을 표시하여 작업 안내 자체가 사라지지 않도록 했습니다.

넓은 화면에서는 기존 외부 작업 추적 패널을 그대로 사용합니다.
