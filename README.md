# 형제 대장간 V0.2.1

플레이테스트 피드백을 반영한 V0.2.1 플레이감 핫픽스입니다.

이번 버전은 V0.2의 하루 운영, OPEN/CLOSED, 실시간 손님, 진열 판매, 제작, 주문, 수면, 저장 구조를 유지하면서 이동감·형제 업무 AI·재료 상인·2층 생활공간·빗자루 진상 퇴치 연출을 개선합니다.

## 가장 쉬운 실행 방법

Windows에서 Node.js가 설치되어 있다면 압축을 완전히 푼 뒤 프로젝트 폴더의 `RUN_GAME.bat`를 더블클릭합니다.

브라우저가 자동으로 `http://localhost:5173`을 엽니다. 검은 서버 창은 플레이 중 닫지 않습니다.

수동 실행:

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

정적 호스팅은 `dist/` 폴더를 배포하면 됩니다. Render Static Site 사용 시 Build Command는 `npm run build`, Publish Directory는 `dist`로 설정합니다.

## 조작

- WASD / 방향키: 이동
- E / Enter: 상호작용 및 제작 타이밍 입력
- Q: 직접 조작할 형제 전환
- I: 창고 / 인벤토리
- 숫자 1~9 또는 마우스: 선택지
- ESC: 창 닫기 / 메뉴

## V0.2.1 주요 변경사항

### 1. 이동속도 개선

- 플레이어 이동속도를 V0.2 초기 기준보다 크게 높였습니다.
- 형은 조금 묵직하게, 동생은 조금 더 빠르게 움직입니다.
- 자동 업무 중 형제의 이동속도도 함께 상향했습니다.

작은 대장간 안에서 작업대 사이를 오가는 시간이 플레이의 방해가 되지 않도록 조정했습니다.

### 2. 형제 작업 AI 상태 시스템

직접 조작하지 않는 형제에게 제작을 맡기면 실제로 다음 상태를 따라 작업합니다.

- GO_TO_WORKSTATION
- WORKING
- DELIVERING
- 역할 업무 WORKING
- IDLE

다른 형제에게 제작을 맡기면 해당 형제가 필요한 작업대를 순서대로 이동하며 자동 제작하고, 완료품을 창고까지 가져갑니다.

목적지 접근이 일정 시간 이상 진전되지 않으면 재접근하는 fail-safe가 있어 영구 정지 상태를 방지합니다.

캐릭터 위에는 현재 업무가 작은 상태 표시로 나타납니다.

- 제작 중
- 카운터 담당
- 화로 관리
- 숫돌 관리

직접 조작 중인 형제는 기존 제작 미니게임을 그대로 사용할 수 있습니다.

### 3. 재료 상인 방문 안정화

상인은 하루에 최소 한 번 반드시 방문합니다.

최신 플레이테스트 수정 기준:

- 오전 보장 방문: 06:00~08:00 사이에 한 번 반드시 도착
- 체류시간: 게임 시간 기준 약 2시간 30분
- 오후 추가 방문: 12:00~18:00 구간에 일정 확률로 한 번 더 방문
- 오후 방문도 약 2시간 이상 머무름

따라서 완전 랜덤 때문에 하루 종일 재료 상인을 보지 못하는 경우가 없습니다.

### 4. 상인 세일

방문마다 일정 확률로 세일이 발생합니다.

예:

- 철 -20%
- 목재 묶음 할인
- 가죽 -15%

첫날 오전에는 시스템을 바로 확인할 수 있도록 철 -20% 세일이 적용됩니다.

세일 중에는 상인 근처와 상점 UI에 SALE 표시가 보입니다.

### 5. 1층 침대 제거 / 2층 생활공간

1층 대장간의 침대를 제거하고 계단을 추가했습니다.

1층은 다음 용도에 집중합니다.

- 제작
- 영업
- 판매
- 재료 관리
- 손님 응대

계단으로 올라가면 별도의 2층 생활공간으로 전환됩니다.

2층 구성:

- 형의 침대
- 동생의 침대
- 작은 테이블
- 수납장
- 창문
- 등불
- 개인 물건
- 1층으로 내려가는 계단

새 게임 및 정상적인 다음 날 시작 시 06:00에 2층에서 기상합니다.

2층에 있는 동안에도 1층의 시간, 손님, 상인, 형제 업무는 계속 진행됩니다.

### 6. 수면

기존 수면 구조는 유지됩니다.

- 22:00 이전: 아직 이르다는 안내
- 22:00 이후: 2층 침대에서 취침 가능
- 자동 제작 중인 형제가 있으면 작업 완료 후 취침하도록 안내
- 02:00 이후: 기존 강제 기절 처리 유지

취침 후 다음 날 06:00에 2층 생활공간에서 시작합니다.

### 7. 빗자루 시스템 재설계

빗자루를 누르는 즉시 NPC를 삭제하는 방식이 아니라 실제 장착형 상호작용으로 변경했습니다.

빗자루를 집어 든 뒤:

- 먼지 근처에서 E: 청소
- 진상 손님 근처에서 E: 진상 퇴치
- 일반 손님 / 기사 / 꼬마 / 상인 / 형제 근처에서 E: 공격하지 않고 안내 메시지

후드 꼬마를 포함한 일반 NPC는 빗자루 때문에 삭제되지 않습니다.

### 8. 진상 손님 빗자루 퇴치

진상에게 빗자루를 사용하면 다음 순서로 처리됩니다.

1. 빗자루를 고쳐 잡음
2. 휘두름
3. 퍽 연출
4. 작은 충격 표시
5. 으악 / 으아악 말풍선
6. 출입구 방향으로 빠르게 도망
7. 문 밖에 도착한 뒤 정상 despawn

형으로 퇴치하면 조금 더 크게 밀려나고 더 빠르게 도망갑니다.

기존 진상 대응도 유지됩니다.

- 할인
- 거절
- 동생 설득
- 형 호출
- 직접 내보내기 후 빗자루 퇴치

## 제작 가능한 아이템

- 단검: 가열 → 성형 → 담금질 → 연마 → 손잡이 조립
- 철검: 가열 → 성형 → 담금질 → 연마 → 손잡이 조립
- 장검: 검 계열 장공정
- 방패: 목재 프레임 → 철판 가열 → 성형 → 조립 → 리벳 → 가죽 손잡이
- 활: 목재 가공 → 휘어잡기 → 시위 연결 → 시험 당기기
- 화살 10개: 화살 축 → 화살촉 → 연결 → 마감

## 알려진 제한사항

- 형제 자동 제작은 현재 작업대 점유 경쟁을 복잡하게 시뮬레이션하지 않습니다. V0.2.1에서는 작업이 확실히 끝나는 플레이감을 우선했습니다.
- 2층은 작은 별도 생활공간이며 자유로운 거대한 건물 내부 맵은 아닙니다.
- 진상 빗자루 연출은 간단한 픽셀 코미디 연출입니다.
- 마을 전체 맵, 전투, 광산, 직원 고용, 대규모 신규 무기는 이번 패치 범위에 포함하지 않았습니다.
