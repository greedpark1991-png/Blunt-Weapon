# 형제 대장간 V0.2

V0.1의 직접 제작 감각을 유지하면서, 손님 수가 아니라 시간의 흐름으로 하루가 진행되는 생활형 대장간 경영 프로토타입입니다.

## 가장 쉬운 실행 방법

Windows에서 Node.js가 설치되어 있다면 프로젝트 폴더의 `RUN_GAME.bat`를 더블클릭합니다.

브라우저가 자동으로 `http://localhost:5173`을 엽니다. 검은 서버 창은 게임을 하는 동안 닫지 않습니다.

수동 실행도 가능합니다.

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

`dist/` 폴더는 정적 웹호스팅에 그대로 올릴 수 있습니다.

## 조작

- WASD / 방향키: 이동
- E / Enter: 상호작용 및 제작 타이밍 입력
- Q: 직접 조작할 형제 전환
- I: 창고 / 인벤토리 확인
- 숫자 1~9 또는 마우스: 선택지
- ESC: 창 닫기 / 메뉴

## V0.2 핵심 하루

- 06:00 시작
- 현실 1초 = 게임 약 1분
- 영업 전 자유 제작 / 청소 / 화로 준비 / 숫돌 관리 / 진열 재고 준비
- 입구 표지판을 직접 OPEN / CLOSED 전환
- OPEN 동안 실시간 랜덤 손님 방문
- 22:00 자동 마감, 이후 신규 손님 생성 중단
- 밤에도 제작 / 재고 정리 / 주문 납품 가능
- 22:00 이후 침대에서 취침 가능
- 02:00까지 버티면 강제 기절 및 다음 날 피로 패널티
- 하루 전체는 메뉴 정지 시간을 제외하면 약 16~20분

## 판매 방식

### 일반 판매

완성품을 판매 진열대 5칸에 직접 올려둡니다. 일반 손님은 진열대를 구경하고 자신의 취향, 가격, 현재 수요에 따라 자동으로 구매하거나 그냥 나갑니다. 따라서 어떤 재고를 미리 만들지 판단하는 것이 중요합니다.

### 즉석 주문

일부 손님, 기사 로데릭, 진상 손님은 카운터에서 직접 주문합니다. 주문을 받은 뒤 손님이 기다리는 동안 제작해 판매합니다.

### 기한 주문

일부 손님은 다음 날 18:00까지 납품하는 주문을 남기고 떠납니다. 완성품을 만든 뒤 카운터 주문장에서 납품하면 주문 보너스와 추가 평판을 얻습니다.

## 제작 가능한 아이템과 공정

- 단검: 가열 → 성형 → 담금질 → 연마 → 손잡이 조립
- 철검: 가열 → 성형 → 담금질 → 연마 → 손잡이 조립
- 장검: 검 계열 공정이지만 더 많은 타이밍 입력과 높은 난이도
- 방패: 목재 프레임 → 철판 가열 → 철판 성형 → 프레임 조립 → 리벳 → 가죽 손잡이
- 활: 목재 가공 → 휘어잡기 → 시위 연결 → 시험 당기기
- 화살 10개: 화살 축 묶음 → 화살촉 준비 → 연결 → 가죽깃 마감

검, 방패, 활, 화살이 같은 화로 → 모루 → 숫돌 루프를 공유하지 않도록 실제 작업대와 미니게임 종류를 분리했습니다.

## 형제 역할

직접 조작하지 않는 형제에게 가까이 가서 E를 누르면 업무를 맡길 수 있습니다.

- 형: 카운터 / 화로·중량 보조 / 대기
- 동생: 카운터 / 연마·정밀 보조 / 대기

카운터를 맡기면 손님의 인내심이 더 천천히 감소합니다. 전문 보조는 관련 제작 공정에 품질 보너스를 줍니다. Q로 해당 형제를 직접 조작하면 맡겨 둔 업무는 해제됩니다.

## 대장간 관리

- 빗자루: 생긴 먼지를 한 번에 청소, 청결 회복, 게임 시간 8분 소비
- 화로 준비: 다음 가열 공정 3회 품질 보너스, 게임 시간 6분 소비
- 숫돌 관리: 다음 연마 공정 3회 품질 보너스, 게임 시간 5분 소비

반복 클릭으로 시간을 늘리지 않고, 할지 말지 판단하는 짧은 운영 선택으로 구성했습니다.

## 세계 이벤트

- 광산 사고: 철 매입가 상승
- 기사단 원정: 장검 / 방패 / 철검 수요 상승, 기사 계열 방문 증가
- 고블린 증가: 모험가 증가, 검 / 방패 수요 상승
- 시장 축제: 방문객 증가, 단검 / 화살 수요 상승
- 폭우: 전체 방문객 감소

새 게임 첫날에는 고블린 증가 소식으로 수요 예측 시스템을 바로 체험할 수 있습니다. 이후 취침 시 다음 날 이벤트가 결정됩니다.
