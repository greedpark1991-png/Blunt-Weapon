# 형제 대장간 V0.2.5

공간 재설계 · 충돌/조작 UX · 생활감 · 명성/단골 기반 개선 업데이트입니다.

V0.2.4의 제작, PERFECT/특성, 날짜/달력, 분기 임대료, 실시간 영업, 재료 상인, 진열/주문, 형제 자동 작업, 1층/2층, 진상/빗자루, AUTO SAVE + SAVE 1~6, 옵션, BGM/SFX를 유지하면서 대장간 내부를 실제로 움직이고 일하는 공간처럼 다시 정리했습니다.

## 가장 쉬운 실행

Windows에서 Node.js가 설치되어 있다면 ZIP을 완전히 압축 해제한 뒤 `RUN_GAME.bat`를 더블클릭합니다.

수동 실행:

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

테스트 / Production build:

```bash
npm test
npm run build
npm run preview
```

Render Static Site:

- Build Command: `npm run build`
- Publish Directory: `dist`

## 조작

게임:

- WASD / 방향키: 이동
- E / Enter: 상호작용, 제작 타이밍
- Q: 직접 조작 형제 전환
- I: 창고
- C: 달력 / 임대료
- ESC: Pause / 뒤로

메뉴:

- ↑ / ↓: 항목 이동
- ← / →: 값 또는 수량 조절
- Shift + ← / →: 상점 수량 ±5, 옵션 음량 ±10%
- Enter / Space / E: 선택
- ESC: 이전 화면 / 닫기
- Delete: 수동 세이브 슬롯 삭제 확인
- 마우스 조작도 그대로 지원

## V0.2.5 핵심 변경

### 1. 공간 충돌과 맵 경계

1층의 화로, 모루, 담금통, 숫돌, 큰 작업대, 판매 카운터, 재료 창고, 장작/석탄 더미, 계단, 진열대 등에 바닥 footprint 기준 충돌을 적용했습니다.

- 플레이어가 가구를 통과하지 않음
- 북쪽 벽과 좌우/아래 경계 밖으로 이동 불가
- 대각선 이동 정규화
- 빠른 속도로 벽 모서리를 밀어도 world bounds 유지
- NPC도 같은 월드 충돌과 경로 시스템 사용

`WorldSystem`이 walkable 검사, 충돌 슬라이딩, A* 기반 경로 탐색, 막힘 재탐색을 담당합니다.

### 2. 작업대 interaction point

형제 AI와 플레이어가 오브젝트 중앙을 목표로 하지 않고 각 작업대 앞의 별도 interaction point를 사용합니다.

화로 → 모루 → 담금통을 가까운 열 작업 라인으로 묶었고, 큰 작업대/숫돌/재료 창고를 왼쪽~중앙 작업 구역에 배치했습니다.

### 3. 새 1층 레이아웃

1층은 크게 두 구역입니다.

- 왼쪽/중앙: WORK ZONE — 장작·석탄, 화로, 모루, 담금통, 큰 작업대, 숫돌, 재료 창고
- 오른쪽: CUSTOMER ZONE — 판매 진열, 손님 대기, ㄱ자 판매 카운터, 출입문

벽면에는 망치/집게/연장걸이, 작업대에는 설계도·금속 조각·가죽끈 등을 추가해 기능 오브젝트 전시장 같은 느낌을 줄였습니다.

계단은 좌측 벽에 붙은 실제 목조 계단 형태입니다.

### 4. Depth Sorting

오브젝트의 `baseY`와 캐릭터 발 위치 Y를 기준으로 그리기 순서를 정합니다.

캐릭터가 작업대 뒤에 있을 때 일부가 가려지고, 아래쪽으로 나오면 앞에 보이도록 구성했습니다.

### 5. 손님 구역 제한

일반 손님/기사/진상은 문 → 진열/카운터 → 문 중심의 CUSTOMER ZONE에서 움직입니다.

화로나 모루 사이로 돌아다니지 않습니다. 후드 꼬마도 손님 쪽 안전 구역을 중심으로 움직입니다.

### 6. 이동속도 추가 상향

V0.2.4 대비 약 20% 추가 상향했습니다.

- 형: 조금 묵직함 유지
- 동생: 조금 더 빠름
- 형제 자동 작업 이동도 실제 게임 진행을 기다리게 하지 않는 수준으로 유지
- 대각선 입력은 √2 가속이 생기지 않도록 normalize

### 7. 화면/폰트

640×360 logical resolution은 유지하되 브라우저에서는 1x/2x/3x 정수 스케일만 사용합니다.

- 1366×768급: 2x 우선
- 1920×1080: 조건이 맞으면 3x
- nearest-neighbor / `image-rendering: pixelated`
- 읽는 텍스트는 `Malgun Gothic`, `system-ui`, `sans-serif` fallback 사용
- HUD/대화/상점/Pause 글자를 이전보다 크게 조정

레트로 느낌은 폰트 왜곡 대신 패널, 색, 픽셀 그래픽으로 유지합니다.

### 8. 키보드 완전 조작

중앙 `UIManager`가 포커스를 관리합니다.

키보드만으로 다음이 가능합니다.

- 타이틀 새 게임 / 이어하기 / 옵션
- ESC Pause
- 저장 / 불러오기
- 덮어쓰기 / 삭제 확인
- BGM/SFX 옵션
- 재료 상점 품목 이동 / 수량 조절 / 구매
- 일반 선택창
- 침대 취침 확인

현재 선택 항목은 금색 외곽선과 ▶ 표시로 강조됩니다.

### 9. CLOSED 조기 취침

대장간이 CLOSED라면 오전/낮이라도 2층 침대에서 즉시 하루를 끝낼 수 있습니다.

OPEN 상태라면 먼저 문을 닫아야 합니다.

진행 중 제작, 손님, 미완료 주문이 있으면 경고를 보여주지만 플레이어가 원하면 하루를 끝낼 수 있습니다. 일찍 잤다는 이유만으로 별도 피로/평판 패널티는 주지 않습니다.

다음 날은 항상 06:00에 시작하며 날짜/요일/임대료/AUTO SAVE가 정상 진행됩니다.

### 10. 오염 위치/종류 다양화

고정 좌표 오염 대신 여러 zone을 사용합니다.

- 화로: 재 / 검댕 / 석탄 부스러기
- 모루: 철가루 / 금속 조각
- 담금질: 물자국 / 철 부스러기
- 숫돌: 숫돌 가루 / 금속 가루
- 작업대: 나무 부스러기 / 가죽 조각
- 입구: 흙 / 진흙 / 발자국
- 카운터: 종이 조각 / 먼지
- 계단/일반 바닥: 먼지

화로/모루/목재 작업/손님 방문 같은 실제 행동이 해당 zone의 오염 확률을 높입니다. 최근 같은 zone 및 너무 가까운 좌표는 반복 확률을 낮추고, walkable floor에만 생성합니다.

### 11. 명성 progression

기존 `reputation` 수치를 새 숫자로 분리하지 않고 UI에서는 명성으로 사용합니다.

- 0~9: 무명의 대장간
- 10~24: 동네에서 소문난 대장간
- 25~49: 마을의 유명 대장간
- 50~79: 인근 지역에 알려진 대장간
- 80~119: 지역 명문 대장간
- 120+: 이름난 형제 대장장이

명성이 올라가면 손님 수를 폭증시키기보다 재방문 확률, 기사/용병/특별 손님, 고급 수요 쪽이 점진적으로 달라집니다.

새 단계 도달 시 짧은 알림이 나오고 ESC 현재 상황에서 단계명과 다음 단계까지 필요한 명성을 볼 수 있습니다.

### 12. 단골 기반

`customerProfiles`에 다음을 저장합니다.

- customerId
- name / type
- visitCount
- purchaseCount
- totalSpent
- relationship
- lastVisitDay
- isRegular
- preferredItems

재방문 손님은 과거 이름과 선호를 재사용할 수 있으며, 3회 이상 방문 또는 2회 이상 성공 거래 + 관계 조건을 만족하면 단골이 됩니다.

단골은 인내심과 구매 성향이 약간 좋아지고 재방문 대사가 달라집니다.

### 13. 명성 기반 특별 손님

대표 해금 기반을 넣었습니다.

- 명성 25: 먼 마을 모험가
- 명성 50: 기사단 병사
- 명성 80: 귀족 집사
- 명성 120: 방랑 영웅

하루마다 무조건 등장하지 않고 조건 충족 후 낮은 확률로 체크합니다.

### 14. 후드 꼬마

매일 고정 등장하지 않고 약 45%의 결정적 방문 규칙을 사용합니다.

방문하면 상황에 따라:

- 오늘의 세계 이벤트 소문
- 재료 상인 SALE 정보
- 대장간 청결 반응
- 모험가/시장 힌트
- 낮은 확률 목재 +1
- 명성/방문 누적 후 향후 견습생 복선

을 제공합니다.

### 15. Save V4

`saveVersion: 4`.

V0.2.4 saveVersion 3 데이터를 불러올 때 새로운 필드가 없어도 기본값으로 마이그레이션합니다.

추가 저장 항목:

- 명성 단계
- 고객 방문/구매/관계 기록
- 단골 상태
- 꼬마 상태/플래그
- 최근 진상 기록
- 오염 type/zone/activity/recent zone

기존 AUTO SAVE + SAVE 1~6 구조와 전역 BGM/SFX 설정을 유지합니다.

## 알려진 제한사항

- 마을 외부 맵은 아직 없습니다. 출입문 상호작용은 현재 대장간 내부 프로토타입 범위를 안내합니다.
- 장작/석탄은 V0.2.5에서 미장센과 화로 준비 기능에 연결되며 본격적인 연료 소비 경제는 아직 없습니다.
- NPC끼리 물리적으로 밀어내는 복잡한 군중 충돌은 사용하지 않습니다. 대신 서로 다른 대기 위치와 경로로 교착을 방지합니다.
- 일반 랜덤 손님의 프레임 단위 좌표를 장기 세이브의 핵심으로 보장하지는 않습니다. 주문/구매/고객 프로필 등 중요한 진행 데이터는 저장됩니다.
- 이 실행 환경에서는 시스템 Chromium headless 프로세스가 DBus/zygote 문제로 종료되지 않아 브라우저 자동 스크린샷 검증을 완료하지 못했습니다. Node 기반 Scene 통합 렌더/플레이 흐름 테스트와 정적 웹서버 응답 검증은 통과했습니다.
