# 형제 대장간 V0.2.4

V0.2.3의 생활감·제작·경제·진상 시스템을 유지한 채, 실제 게임에 필요한 기본 UX를 추가한 통합 업데이트입니다.

이번 버전의 핵심은 다음 네 가지입니다.

- ESC 슬라이드형 일시정지 메뉴
- AUTO SAVE + 수동 SAVE 1~6 다중 세이브
- BGM / SFX 독립 옵션과 전역 설정 저장
- 첨부 음원 `The_Artisan_s_Hearth.mp3`의 실제 프로젝트 적용

기존 V0.2.3의 이동속도 상향, 벽면형 계단, 재료 다중 구매, 야간 조명, PERFECT 정밀 제작, 제작 특성, 날짜/요일, 분기 임대료, 다양한 진상 및 구매 기록 연동 기능도 함께 포함합니다.

## 가장 쉬운 실행 방법

Windows에서 Node.js가 설치되어 있다면 ZIP을 **완전히 압축 해제한 뒤** 프로젝트 폴더의 `RUN_GAME.bat`를 더블클릭합니다.

브라우저가 `http://localhost:5173`을 엽니다. 플레이 중에는 함께 열린 검은 서버 창을 닫지 않습니다.

수동 실행:

```bash
npm install
npm run dev
```

테스트 및 Production build:

```bash
npm test
npm run build
npm run preview
```

Render Static Site 기준:

- Build Command: `npm run build`
- Publish Directory: `dist`

## 기본 조작

- WASD / 방향키: 이동
- E / Enter: 상호작용 / 제작 타이밍 입력
- Q: 직접 조작할 형제 전환
- I: 창고 / 인벤토리
- C: 달력 / 임대료 확인
- ESC: 일시정지 메뉴 / 뒤로가기
- 마우스: 메뉴, 세이브, 상점, 옵션 조작

## V0.2.4 핵심 변경사항

### 1. ESC 일시정지 메뉴

게임 중 ESC를 누르면 화면 오른쪽에서 중세풍 패널이 슬라이드되어 나옵니다.

메뉴가 열린 동안 다음 진행은 멈춥니다.

- 게임 시간
- 손님 이동과 인내심
- NPC 이동
- 형제 자동 작업
- 제작 미니게임
- 영업 시간
- 랜덤 손님 / 이벤트 진행

ESC를 다시 누르면 즉시 게임으로 복귀합니다.

현재 상황 영역에는 다음이 표시됩니다.

- 연도 / 월 / 일 / 요일
- 현재 시간
- OPEN / CLOSED
- Gold / 평판
- 철 / 목재 / 가죽
- 현재 주문 개수
- 진열 중인 상품 수
- 다음 임대료 이름 / 남은 날짜 / 금액

메뉴 구성:

- 게임 계속하기
- 저장하기
- 불러오기
- 옵션
- 메인 메뉴로

### 2. 제작 중 ESC

제작 미니게임 도중 ESC를 눌러도 제작이 취소되거나 실패하지 않습니다.

- 게이지와 입력 횟수는 그대로 유지
- Pause 중 게이지 진행 정지
- 복귀 후 약 0.38초 입력 유예

따라서 ESC를 누른 순간의 제작 상태에서 자연스럽게 이어집니다.

### 3. 다중 세이브 슬롯

수동 저장 슬롯 6개를 제공합니다.

- SAVE 1
- SAVE 2
- SAVE 3
- SAVE 4
- SAVE 5
- SAVE 6

자동 저장은 별도 `AUTO SAVE`를 사용하며 수동 슬롯을 덮어쓰지 않습니다.

각 슬롯에는 다음 정보가 표시됩니다.

- 게임 날짜
- 현재 시간
- Gold
- 평판
- 누적 플레이 시간
- 실제 최근 저장 시각

기존 데이터가 있는 슬롯에 저장하면 덮어쓰기 확인창이 나타납니다.

수동 세이브 삭제도 확인창을 거친 뒤 처리됩니다.

### 4. 이어하기 개선

타이틀 화면의 이어하기는 마지막 저장을 즉시 불러오지 않습니다.

`AUTO SAVE + SAVE 1~6` 목록을 보여주고 원하는 시점을 직접 선택합니다.

### 5. 저장 안정성

현재 저장 버전은 `saveVersion: 3`입니다.

V0.2 계열 및 초기 세이브를 가능한 범위에서 마이그레이션합니다.

각 슬롯은 서로 다른 localStorage 키를 사용하므로 한 슬롯이 손상되어도 다른 슬롯을 직접 덮어쓰거나 삭제하지 않습니다.

저장되는 주요 상태:

- 날짜 / 요일 / 시간
- Gold / 평판
- 재료
- 완성품과 제작 특성
- 진열대
- 주문
- 형제 업무 상태
- 제작 진행 상태
- 일반 손님 상태
- 기사 / NPC 기록
- 구매 / 무기 역사
- 외상 장부
- 임대료 / 연체
- 세계 이벤트
- OPEN / CLOSED
- 1층 / 2층
- 형제 위치
- 꼬마 / 상인 방문 상태
- 빗자루 상태
- 플레이 시간

### 6. 옵션 메뉴

타이틀 화면과 ESC 메뉴에서 오디오 설정을 조절할 수 있습니다.

- BGM 0~100%
- SFX 0~100%
- BGM 음소거
- SFX 음소거

BGM과 효과음은 서로 독립적입니다.

기본값:

- BGM 65%
- SFX 80%

옵션은 게임 세이브와 별도의 전역 설정 `blacksmith-brothers-globalSettings-v1`에 저장되어 어떤 세이브를 불러와도 그대로 유지됩니다.

### 7. 실제 첨부 BGM 적용

사용자가 제공한 `The_Artisan_s_Hearth.mp3`의 실제 음원 데이터를 프로젝트에 포함했습니다.

프로젝트 경로:

`assets/audio/bgm/the_artisans_hearth.mp3`

동작:

- 페이지를 연 즉시 강제 재생하지 않음
- 새 게임 또는 세이브 불러오기를 클릭하면 재생 시작
- 반복 재생
- 1층 ↔ 2층 이동 시 끊기지 않음
- 취침 → 다음 날 진행 시 중복 생성되지 않음
- 저장 → 불러오기 시 같은 AudioManager 인스턴스를 재사용
- ESC 중 음악은 멈추지 않고 약 65% 수준으로 살짝 낮아짐
- 복귀하면 기존 사용자가 설정한 볼륨으로 돌아옴

### 8. AudioManager 역할

`SoundFX` 시스템이 BGM과 SFX를 중앙 관리합니다.

현재 제공 기능:

- `startBGM()`
- `stopBGM()`
- `setBGMVolume()`
- `setSFXVolume()`
- `muteBGM()`
- `muteSFX()`
- `setDucked()`
- 각종 제작 / 판매 / UI 효과음

향후 낮, 밤, 축제, 마을, 광산 BGM을 추가하기 쉬운 형태입니다.

## V0.2.3에서 유지된 핵심 시스템

### 빠른 이동과 형제 자동 작업

- V0.2.2 대비 플레이어 이동속도 추가 상향
- 형은 조금 묵직하고 동생은 조금 빠른 이동 차이 유지
- 형제 자동 제작 상태 머신
- 작업대 이동 → 작업 → 결과물 전달까지 자동 수행
- 정지 방지 fail-safe

### 재료 상인

- 매일 06:00~08:00 보장 방문
- 게임 시간 약 2시간 30분 체류
- 12:00~18:00 사이 일정 확률로 추가 방문
- 철 / 목재 / 가죽 SALE
- 상점 UI는 직접 닫을 때까지 유지
- 수량 `-10 / -1 / +1 / +10 / MAX`
- 총 가격 표시 및 일괄 구매

### 1층 / 2층 생활공간

- 1층은 제작 / 영업 중심
- 벽면형 목조 계단
- 2층 형 / 동생 침대와 생활공간
- 22:00 이후 직접 침대에서 취침
- 다음 날 06:00 2층 기상

### 야간 조명

- 창문 색상이 시간대에 따라 변함
- 밤에는 낮의 빛줄기 제거
- 실내 전체 암전 대신 화로 / 등불의 따뜻한 빛 강조

### 제작 PERFECT와 특성

기존 품질:

- 조악
- 평범
- 우수
- 명품

성공 구간 내부에 더 좁은 금빛 PERFECT 판정을 추가했습니다.

PERFECT 성공 횟수가 많을수록 아이템 계열에 맞는 특성이 붙을 가능성이 높아집니다.

예:

- 날카로운
- 잘 벼린
- 균형 잡힌
- 뛰어난
- 빛나는
- 단단한
- 견고한
- 정교한

특성 배율은 기존 품질 배율과 중첩되어 판매가에 반영됩니다.

Day 2부터 진상이 등장하기 시작하며 너무 오랫동안 한 번도 나오지 않는 상황을 보정합니다.

지원되는 대표 유형:

- 내구도 책임전가
- 외상 영웅 허풍쟁이 베른
- 마법 폭발 책임전가
- 자연주의 엘프
- 라떼는 드워프
- 옆 마을 비교형
- 원가 계산기
- 마감 직전 손님
- 환불 빌런
- 과도한 주문 변경

구매 기록과 연결 가능한 진상은 실제 플레이어가 과거 판매한 무기 기록을 참조합니다.

외상 NPC의 빚은 누적 기록됩니다.

빗자루 퇴치는 기존처럼 즉시 삭제가 아니라 `퍽 → 으악 → 출입구로 도망 → 퇴장` 순서로 처리됩니다.

## 알려진 제한사항

- 현재 프로젝트는 640×360 Canvas 기반 프로토타입이며 대규모 마을 맵은 없습니다.
- 일반 손님의 좌표와 상태도 저장하지만, 향후 AI 구조 변경 시 이전 버전 세이브의 랜덤 손님은 안전한 기본 상태로 마이그레이션될 수 있습니다.
- BGM은 현재 한 곡입니다. 시스템은 다중 BGM 확장을 고려해 중앙 관리하지만 낮/밤 곡 전환 자체는 아직 없습니다.
- 효과음은 외부 저작권 음원 대신 Web Audio 기반의 간단한 게임 효과음입니다.
- 이 환경의 관리 정책 때문에 Headless Chromium에서 localhost/file URL 직접 접근은 차단되어, 최종 브라우저 검증은 Node Scene 통합 테스트 + 정적 HTTP 응답 검사로 대체했습니다. 실제 사용자 브라우저에서는 `npm run dev` 또는 Render Static Site로 실행합니다.
- 마을 전체 맵, 전투, 광산 탐험, 직원 고용, 대규모 신규 무기/퀘스트는 이번 범위가 아닙니다.
